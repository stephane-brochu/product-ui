# Product UI 0.8.0 migration

Install the needed items from the 0.8.0 snapshot. The wedding platform uses `core,foundations,field-control,tabs,multi-select,reorderable-list,workspace-shell` with `--namespace product-ui`. This installs components under `src/components/product-ui` and leaves the existing public-site components in place. Declare the exact Radix Dialog and Popover dependencies before installation.

Import the installed styles and wrap the workspace in `ThemeBoundary` with `theme="wedding-admin"` so overlay portals use the same tokens. Keep routes, preferences and server actions in product adapters. See Wedding admin in the catalogue for an interactive example.
