# Product UI 0.9.0

This release completes the reusable presentation layer needed by the Wedding admin migration.

- `Table` accepts `mobileLayout="stack"`. Cells supply their compact label with `data-label`; the primary cell can use `ds-table-primary`. The DOM remains a native table and print returns to table layout.
- `CategoricalShareChart` receives finite, non-negative values plus exact caller-formatted labels. It calculates only visual proportions; totals, money formatting and category selection remain product responsibilities.
- `HtmlPreview` uses a fixed sandbox and no-referrer policy. The product supplies already-rendered HTML and retains content generation, authorization and send behavior.
- `DevicePreviewFrame` owns only viewport framing and scale. Routes, preview state, content, query parameters and access rules remain product responsibilities.

Install the optional items `categorical-share-chart` and `preview`, import `ui-preview.css`, then deliberately replace product-owned presentation wrappers. Existing release snapshots remain immutable.
